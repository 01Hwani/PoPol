핵심 강점

데이터 기반 의사결정

직관이 아닌 객관적인 데이터를 분석하여 현장의 근본적인 문제를 도출하고 가장 효과적인 해결책을 제시합니다.

문제 해결을 위한 실행력

문제를 회피하지 않고 주도적으로 자처하며, 유관 부서와의 적극적인 협업을 통해 실질적인 개선안을 실행에 옮깁니다.

분석 툴 활용 역량

파이썬(Python) 등 데이터 분석 도구를 활용하여 방대한 데이터를 처리하고, 자동화된 예방 코드를 작성하여 효율성을 극대화합니다.

역량 및 주요 경험

현장의 데이터를 실질적인 성과로 연결한 사례입니다.

01

불량률 4% 감소 달성

지속적인 제품 불량 발생 문제 해결

  • 고질적인 불량 문제 해결을 자처하여 프로젝트 리드
  • 데이터 분석을 통해 불량의 근본 원인 도출
  • 유관부서와 적극적으로 협업하여 개선안 수립
  • 새로운 지그(Jig) 제작안 도출 및 적용
  • 결과: 전체 불량률 4% 감소 성공
02

파이썬 활용 수율 개선

반도체 수율 저하 문제 근본 원인 해결

  • 반도체 수율 저하 현상 발생 시 데이터 기반 접근
  • 수율 데이터와 설비교체 이력을 교차 검증 분석
  • 수율 저하의 귀책 공정 정확히 도출
  • 파이썬(Python)을 활용하여 자동화된 예방 코드 작성
  • 결과: 귀책 공정 파악 및 예방 코드로 근본 원인 해결
